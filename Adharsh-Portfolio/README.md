# Adharsh S — Portfolio

Personal portfolio website for Adharsh S, B.E. Computer Science and Engineering student at Nandha Engineering College.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile navigation
- `assets/Adharsh_S_Resume.docx` — resume

## Run
Open `index.html` in a browser.

## Deploy
Create a GitHub repository, upload these files, then enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → / (root)
